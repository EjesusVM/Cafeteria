# Proyecto Cafeterias

Sitio web de una cafetería desarrollado con **React + TypeScript + Vite**.
Proyecto enfocado en estructura, reutilización de componentes y navegación por rutas.

## Demo
 https://TU-LINK-DE-NETLIFY.netlify.app

## Tecnologías
- React
- TypeScript
- Vite
- React Router
- CSS

## Estructura del proyecto
- Componentes reutilizables (Header, Footer, Galería, Menú)
- Páginas separadas por rutas
- Navegación dinámica con `NavLink`
- Layout persistente (Header/Footer)

## ✨ Funcionalidades
- Navegación SPA
- Rutas dinámicas
- Componentes reutilizables
- Diseño responsive
- Deploy en Netlify
